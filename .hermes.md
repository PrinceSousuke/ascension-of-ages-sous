# Ascension of Ages — authoring canon (Hermes)

NeoForge 1.21.1 CurseForge modpack. Quest layer: FTB Quests
(`config/ftbquests/quests/chapters/*.snbt`).

Full canon: `AOA_AGENT_CANON.md` at the repo root. Read it before creating or
editing any quest, chapter, KubeJS script, or config. Load-bearing rules:

- **Age-tier discipline.** 8 ordered ages: `dark_ages`, `medieval_times`,
  `the_renaissance`, `industrial_revolution`, `gilded_age`, `atomic`,
  `otherworldly`, `ascension`. A quest may only require items/mods/mechanics
  legal at or before its chapter's age. Later-tier tech in an earlier age (e.g. a
  diving suit in a Dark Age line) is a hard defect and usually a softlock.
  Confirm each item's unlock stage against
  `kubejs/server_scripts/aoa_astages_*.js` before placing it.
- **Verify, never assume.** Never reference a mod/item/block/tag/mechanic
  without confirming it exists on disk or in the actual jar. Never guess an item
  ID. If you cannot verify it, say so and stop — do not fabricate.
- **FTBQ.** Preserve `.snbt` byte structure; coordinate-only edits for layout.
  Do NOT strip the `SkillsLevel` block (inert, regenerates). Only real, verified
  More Quest Types task IDs.
- **Layout.** Dependency lines must not cross. No filler or duplicate quests.
  Quality over density; never pad to a count.
- **Prose.** Instruction-first, teach the mechanic, no em dashes, no AI-isms.
- **Tooling truth.** The editor mount can misreport truncation; use Desktop
  Commander or `node --check` as ground truth. Authoritative docs live under
  `AoA redo/`.
