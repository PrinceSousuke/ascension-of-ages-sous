# Severance Array Outline

## Purpose

This is the basic planning outline for a future Ascension-age prestige structure.

It is not a live SNBT implementation yet.

The structure exists to give Ascension a final off-world mega-project that feels:

- deliberate
- prestigious
- system-proving
- irreversible once armed
- still useful after activation

## Core Identity

- Canonical name: `Severance Array`
- Age owner: `Ascension`
- Build site: off-world, preferably a settled remote planet rather than the origin world
- Tone: large, esoteric, industrial-cosmic, and final without devolving into raw-material absurdity
- Strategic role: a Ballistix-linked severance weapon/platform aimed at the player's origin world
- Activation tone: final and irreversible-feeling
- Post-completion role: remains a usable late-game strategic and logistics structure after firing

## Major Beat Outline

### 1. Off-World Charter

Purpose:
- establish the Array site on a real off-world surface

Proves:
- launch competence
- remote construction logistics
- stable life-support presence

Feeds from:
- `space_launch_infrastructure_and_stellaris`
- `space_orbital_life_support_and_logistics`

### 2. Foundation Ring

Purpose:
- build the outer frame and anchor ring that defines the Array footprint

Proves:
- large-scale structure assembly
- late power-routing discipline

Feeds from:
- `space_ender_io_networks`
- `space_advanced_storage_and_digital_networks`

### 3. Mastery Segment A: Hazard Core

Purpose:
- install the hazardous energy and containment heart of the structure

Proves:
- Nuclear mastery
- reactor and chemical discipline
- strategic-force safety

Feeds from:
- `nuclear_reactors_isotopes_and_hazardous_power`
- `nuclear_strategic_power_and_hardened_grids`
- `nuclear_defense_systems_and_strategic_force`
- `nuclear_chemical_storage_and_digital_bridges`

### 4. Mastery Segment B: Cosmic Relay Spine

Purpose:
- bind the Array into Space-age power, storage, and remote-control infrastructure

Proves:
- off-world network scale
- cross-site control
- long-distance energy/logistics integration

Feeds from:
- `space_advanced_storage_and_digital_networks`
- `space_antimatter_and_cosmic_refinement`

### 5. Mastery Segment C: Prestige Fabrication

Purpose:
- construct the prestige-grade fabricators, shells, and precision components

Proves:
- late fabrication convergence
- multi-system crafting
- final assembly discipline

Feeds from:
- `ascension_prestige_crafting`
- `ascension_projecte_exchange_ethics`
- `ascension_avaritia_capstones`

### 6. Origin Lock

Purpose:
- bind the Array to the player’s original world / old base coordinates

Proves:
- intentional severance target selection
- that the structure is aimed and contextual, not decorative

Feeds from:
- Ballistix strategic-force branch
- Space remote logistics

### 7. Severance Protocol Armament

Purpose:
- install the final targeting, launch, and authorization systems

Proves:
- militarized control
- catastrophic restraint
- final command authority

Feeds from:
- `nuclear_defense_systems_and_strategic_force`
- future `space_launch_threshold`

### 8. Irreversible Activation

Purpose:
- fire the Array and complete the severance event

Proves:
- final commitment
- prestige completion

Feeds from:
- all prior beats
- future `ascension_boss_hunts`

### 9. Post-Completion Function

Purpose:
- keep the Array meaningful after activation

Candidate functions:
- remote launch-control platform
- off-world antimatter / hazardous logistics hub
- prestige teleport / relay anchor
- final-world severance memorial and utility site

## Implementation Rules For Later

- do not reduce the structure to bulk-count filler
- gate major beats by mastery proofs, not only by item totals
- keep the build off-world so it reads as final expansion, not base clutter
- keep Ballistix integration visible all the way through authorization and activation
- require a hardened-grid proof so Ascension severance control clearly descends from Nuclear strategic-force infrastructure
- preserve meaningful post-completion utility so the Array is not a one-use cutscene prop
